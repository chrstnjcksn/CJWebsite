# CJWebsite

Responsive portfolio website for Christian Jackson.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and has no package installation step.

Portfolio artwork and interface marks in `public/assets/` are local exports from the Home, Personal Art, About, and Resume Figma files. Open `personal-art.html` to view the Personal Art page, `about.html` to view the About page, or `resume.html` to view the Resume page.
